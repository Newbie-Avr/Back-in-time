How to Start LM Studio Server

Simple 3-step setup on Windows 11.

1
Open LM Studio & Download a Model

Launch LM Studio. Search for a model such as Gemma 2 (2B, 9B), Llama 3.2, or Mistral and click Download.

2
Go to the Local Server Tab

Click the <> (Developer / Local Server) tab on the left navigation bar in LM Studio.

3
Start Server on Port 1234

Select your downloaded model from the top dropdown, verify the port is set to 1234, and toggle Start Server. Then return here and click Test Connection.

💡
Tip: LM Studio works completely offline. You do not need an active internet connection once your model is downloaded.

Privacy & Security Disclosures

Transparent data handling guidelines.

  • Browser-Local Storage: Memory records are held in your browser's localStorage. While protected by your browser's origin boundary, it is not hardware-encrypted.
  • No Cloud AI Transmission: All AI requests are handled through our local Node.js proxy to your loopback address (127.0.0.1). No external AI providers, tracking, or cloud servers receive your family stories.
  • Audiovisual Preservation: Keep digital backups of your home recordings, tapes, and photographs.
